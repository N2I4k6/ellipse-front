# 🍇 Ellipse — Frontend

## 📖 О проекте

Веб-приложение для помощи в поиске работы. Позволяет вести воронку откликов по компаниям, готовиться к собеседованиям через тесты и документацию, вести резюме, генерировать сопроводительные письма с помощью AI, получать уведомления о событиях. Данные получает по REST API бэкенда.

- React Router
